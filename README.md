# PRIVET для iPhone и iPad

Нативное приложение-оболочка (Swift, SwiftUI + WKWebView) с интерфейсом PRIVET. Открывает веб-клиент
`https://svt.wvw.su/privet/web/`, поэтому новые версии интерфейса приходят сами, без переустановки.
Вход хранится в постоянном хранилище приложения (не стирается через 7 дней, как в Safari).

## Как получить .ipa (бесплатно, без Mac)

1. Создайте репозиторий на GitHub (**публичный** — у публичных репозиториев сборки на macOS бесплатны;
   в приватных они расходуют платные минуты) и загрузите в него **содержимое этой папки**
   (в корне должны лежать `project.yml`, `PRIVET/` и `.github/`).
2. Вкладка **Actions** → «Сборка iOS (.ipa без подписи)» → **Run workflow**. Сборка занимает 5–10 минут.
3. Откройте завершённый запуск → внизу **Artifacts** → скачайте `PRIVET-ios-unsigned` (внутри `PRIVET.ipa`).

## Как поставить на iPhone

Файл собран без подписи, поэтому его нужно подписать вашим Apple ID при установке:

- **Sideloadly** (Windows/Mac) или **AltStore**: подключите iPhone кабелем, выберите `PRIVET.ipa`, войдите своим Apple ID.
  Бесплатный Apple ID даёт приложение на **7 дней**, максимум 3 приложения; затем установку нужно повторить
  (AltStore продлевает сам, пока включён AltServer).
- На iPhone: Настройки → Основные → VPN и управление устройством → доверьтесь своему Apple ID.
- Если нужна установка на год без возни — платный аккаунт Apple Developer (99 $/год) и TestFlight.

## TestFlight

Ссылку TestFlight может выдать только владелец платного аккаунта Apple Developer. Есть готовый
`testflight.yml` (запуск вручную): добавьте секреты, перечисленные в начале файла, — сборка уйдёт в TestFlight,
а ссылку приглашения вы создаёте в App Store Connect.

## Что внутри

- `project.yml` — описание проекта для XcodeGen (проект Xcode создаётся при сборке).
- `PRIVET/ContentView.swift` — окно веб-клиента, права на микрофон и камеру, окна подтверждения, внешние ссылки в Safari.
- `PRIVET/Assets.xcassets` — значок и цвет экрана запуска.

Возможности: тот же клиент, что в веб-версии PRIVET, — сквозное шифрование (ключи хранятся в приложении), звонки и групповые звонки, голосовые и видеокружки, игры, опросы, музыка, плагины, стикеры и подарки.
Ограничения: нет push-уведомлений при закрытом приложении, расшифровки голоса на устройстве и ИИ-модели; ленты со сторис нет; подтверждение устройств по эмодзи пока недоступно (ключи можно перенести файлом или из резервной копии).
